# 🍔 Mahelo's Burguer al Carbón • Minca, Santa Marta

> **El Auténtico Sabor al Carbón en la Sierra Nevada de Santa Marta.**  
> Aplicación web gastronómica e interactiva desarrollada con React 19, TypeScript, Tailwind CSS y Framer Motion, con sistema dinámico de personalización de pedidos y checkout directo vía WhatsApp API.

---

## 🌟 Características Principales

- **🔥 Menú Oficial al Carbón:** Carta 100% fiel con gramajes reales (180g, 220g y 240g mixta), pan de mantequilla, quesos Colby Jack/mozzarella y el sello distintivo de papitas criollas doradas.
- **👶 Sección Kids ("Para los Más Chicos"):** Sándwiches tradicionales y combo de mini perros calientes con papas en bastón.
- **🥤 Bebidas Tradicionales de 16 oz:** Limonadas naturales, limonada cerezada, agua de panela con limón y cervezas bien frías.
- **✨ Experiencia Interactiva & Animaciones:** Transiciones fluidas con Framer Motion, modales de adiciones y micro-interacciones.
- **🛵 Carrito & Generador de Pedidos por WhatsApp:** Formulario adaptado a Minca (entregas a hostales/cabañas, mesas o para llevar) que formatea automáticamente la orden con emojis y cálculos en Pesos Colombianos (COP).
- **📸 Muro de Comunidad Instagram:** Integración directa con [@mahelos_burger](https://www.instagram.com/mahelos_burger/).
- **📍 Localización en Minca:** Información de contacto, horarios y mapa interactivo.

---

## 🛠️ Stack Tecnológico

- **Frontend:** React 19 + TypeScript
- **Bundler:** Vite 8
- **Estilos:** Tailwind CSS v4
- **Animaciones:** Framer Motion
- **Iconografía:** Lucide React
- **Despliegue:** Vercel (Configurado para SPA routing)

## 🚀 Instalación y Desarrollo Local

1. **Clonar el repositorio:**
   ```bash
   git clone https://github.com/TU_USUARIO/mahelos-burguer.git
   cd mahelos-burguer
   ```

2. **Instalar dependencias:**
   ```bash
   npm install
   ```

3. **Ejecutar el servidor local:**
   ```bash
   npm run dev
   ```
   Abre [http://localhost:5173/](http://localhost:5173/) en tu navegador.

4. **Compilar para producción:**
   ```bash
   npm run build
   ```
